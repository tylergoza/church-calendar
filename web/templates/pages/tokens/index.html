API tokens

Tokens let another site or app read events. A token sees public events and when rooms are busy; tick "Can see private events" to show private events' details too (never locked ones). Apps that send their events here get their own tokens with the push API.

What it can read

JSON from {{.APIBase}}, with from and to dates (YYYY-MM-DD, at most 400 days apart) and an optional room:

  • GET /events: events in the range, each with its source (events, productions, calendar or request). Ones the token can't see show as busy, with only their rooms and times.
  • GET /events/{id}: one event the token can see.
  • GET /events.ics: the same as a calendar feed; it also takes ?token=.

No token is needed for {{.CalendarURL}}, the public calendar feed: public events, and busy times for the rest.
